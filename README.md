# LITHOMANCER PRO

A Streamlit application for mineral identification based on Specific Gravity (SG).

## Setup

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Run the application:
   ```bash
   streamlit run lithomancer.py
   ```

## Usage

1. Enter the weight of the mineral in Air (g).
2. Enter the weight of the mineral in Water (g).
3. Click "RUN FORENSIC ANALYSIS".
4. View the calculated Specific Gravity and any matching minerals from the database.
